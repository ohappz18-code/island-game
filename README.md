# เกาะร้าง: เอาชีวิตรอด (Android APK)

## สร้าง APK ผ่าน GitHub (ไม่ต้องลงอะไรในคอม)
1. สร้าง repository ใหม่บน GitHub (Private ก็ได้) แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (รวมโฟลเดอร์ `.github`)
2. ไปที่แท็บ **Actions** → เลือก **Build APK** → **Run workflow** (รอประมาณ 5–10 นาที)
3. เปิดงานที่รันเสร็จ → ส่วน **Artifacts** → ดาวน์โหลด `island-survival-apk` → แตกไฟล์ได้ `app-debug.apk`
4. ส่งเข้าโทรศัพท์แล้วติดตั้ง (ต้องเปิด "ติดตั้งจากแหล่งที่ไม่รู้จัก")

## แก้เกม
แก้ไฟล์ `www/index.html` แล้วรัน Build APK ใหม่

## ที่ตั้งไว้ให้
ชื่อแอป เกาะร้าง · ล็อกแนวนอน · เต็มจอ ซ่อมแถบระบบ · ไอคอนเกาะมะพร้าว · package `com.islandsurvival.game`
